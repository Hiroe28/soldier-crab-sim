# ミナミコメツキガニ シミュレーション（試作）

「少し進んで止まる」「触られたら止まって、触った相手の向きに合わせる」というルールだけで群れが生まれるかを試すための、ブラウザで動くシミュレーションです。

- 依存ライブラリなし。`index.html` をブラウザで開くだけで動きます。
- スマホでも動きます。個体をタップすると追跡、空いた場所をタップすると「手で触った」扱い、ドラッグで視点移動、ホイールか「拡大」スライダーで寄れます。
- フィールドは既定で画面の2倍四方で、最初は全体が見えています。拡大すると右下に全体図と今見ている範囲が出ます。「広さ」で変えられ、「最初の配置」で全体に散らばるか中央にかたまるかを選べます。

## 公開方法（GitHub Pages）

1. このフォルダを GitHub の公開リポジトリに push する。
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` の `/ (root)` にする。
3. 数十秒後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる。

## 画面の見方

| 項目 | 意味 |
|---|---|
| 色 | 個体ごとに固定（同じ色は同じ個体）。「色の意味」で進行方向に切り替えられる。 |
| ハサミと目のある側 | 前（進行方向）。ミナミコメツキガニは前向きに歩く。 |
| 薄い線 | 直近1秒ほどの軌跡（「軌跡を表示」で消せる） |
| 細い灰色の輪 | 自分の都合で止まっている |
| 太い黒の輪 | 触られて、相手の向きに合わせようとしている |
| 点線の丸 | タップして追跡中の個体。もう一度タップで解除。既定では画面の中心に追い続ける。 |
| 整列度 | 全個体の向きベクトルの平均の長さ。0でバラバラ、1で全員同じ向き。 |
| 最大の群れの割合 | 体の1.5倍以内でつながった最大の集団に、全体の何割がいるか。 |
| 3匹以上の群れにいる割合 | 同じつながり方で、3匹以上の集団に入っている個体の割合。小さなかたまりが多数できる場合はこちらに出る。 |
| 接触回数 | 直近5秒間に「触られた」判定が起きた回数。 |

## 決め打ちしている点（先生に確認したいこと）

1. 「触った」の判定は、動いている個体が進行方向側の相手にぶつかったとき。止まっている個体は誰も触らない。
2. 両方が動いていて正面からぶつかると、二匹とも止まり、二匹の進行方向ベクトルを合成した向きに進む（先生の案）。ちょうど真逆で合成がゼロになるときは、止まっていつも通り次の向きを選ぶ。比較用に「向きを交換」も選べる。
3. 触られて止まっている間の接触は無視する（最初に触った相手を優先）。
4. 「ランダムに方向を変える」は既定で完全ランダム。スライダーで「前の向きを少し変える」程度にもできる。
5. 向きを合わせたあと一歩進んだら、通常どおり止まってランダムに向きを変える。
6. フィールドの端に当たった個体は、それ以上進めないので止まり、いつも通り次の向きを選ぶ。端をつなげる（反対側に現れる）ことも、跳ね返ることもしない。

## 一歩先の予期（既定ではオフ）

郡司ペギオ幸夫『群れは意識をもつ』第3〜4章の相互予期モデルを参考に、次の二つを、「進んで止まる」「触られたら止まる」はそのままに加えた。プリセット「予期：仲間と重なる先へ進む」で試せる。

- **一歩先を予期する**：止まったとき、前方の扇形（角度は「ばらつき」）に「候補の数」だけ行き先候補を作る。近くの個体の候補と重なる（体の直径以内にある）候補に進み、重なりが最も多い候補を選ぶ。重なる候補がなければ、「仲間と重ならなくても進む確率」でだけ候補のどれかへ進み、それ以外は動かない。本のモデルでは重ならなければ動かないが、実データでは実際の移動の約26%が重なりのない場所への移動だったため、この確率を設けた。フィールドの外や他個体の上にある候補は無効。
- **空いた場所に入る（追尾）**：重なる候補がないとき、近くの個体が去った場所が一歩以内なら、そこへ向かう。

本のモデルは格子上で、向きを揃える規則なしに群れができるとしている。ここでは連続平面と「進んで止まる」の断続運動に置き換えているので、忠実な再現ではない。

## 試作段階での観察（フィールド2倍四方、各条件1回ずつ）

### 基本ルールだけ（約160秒）

| プリセット | 整列度 | 最大の群れ | 3匹以上の群れ | 接触（5秒） |
|---|---|---|---|---|
| 基本（完全ランダム転向、50匹） | 0.03 | 4% | 0% | 7 |
| 基本で個体数を増やす（200匹） | 0.02 | 2% | 0% | 153 |
| 基本で向きを少しずつ変える（30°、80匹） | 0.14 | 4% | 0% | 55 |
| 対照：触れても向きを合わせない（30°、80匹） | 0.04 | 3% | 0% | 949 |
| 一歩を短く（体2個ぶん） | 0.20 | 2% | 0% | 7 |

整列度は全員バラバラでも 1/√N 程度（50匹で約0.14、80匹で約0.11）の値が出るので、その程度は「揃っていない」と読む。ばらつきを5°まで下げると「最大の群れ」が30%を超えるが、画面を見ると縁に張り付いた渋滞であって群れではない。対照の接触回数が多いのは、向きを合わせないと同じ相手を押し続けて何度も「触った」判定になるため。

**結論**：基本ルールだけでは、どの条件でも3匹以上のかたまりは一つもできない。

### 一歩先の予期を足した場合（一歩＝体2個ぶん、ばらつき180°、候補20個、80匹、重ならなくても進む確率0%）

| 条件 | 整列度 | 最大の群れ | 3匹以上の群れ | 接触（5秒） |
|---|---|---|---|---|
| 予期＋追尾、160秒 | 0.09 | 5% | 24% | 148 |
| 予期＋追尾、480秒 | 0.19 | 6% | 35% | 244 |
| 候補10個、160秒 | 0.12 | 6% | 26% | 138 |
| 150匹、160秒 | 0.11 | 4% | 41% | 471 |
| 予期のみ（追尾なし）、160秒 | 0.09 | 6% | 18% | 155 |
| 追尾のみ（予期なし）、160秒 | 0.05 | 3% | 0% | 32 |
| ばらつき120°、160秒 | 0.08 | 3% | 0% | 49 |
| 重ならなくても進む確率20%、160秒 | 0.15 | 5% | 28% | 172 |
| 同上、480秒 | 0.08 | 6% | 28% | 216 |
| 重ならなくても進む確率50%、160秒 | 0.18 | 5% | 16% | 209 |

- 「重なる候補にしか進まない」を入れると、2〜6匹の小さなかたまりが多数でき、時間とともに増える。かたまりは一緒に動く。
- 「重ならなくても進む確率」は20%程度なら群れの割合をほぼ落とさず、孤立した個体が待ち続けることもなくなる。50%まで上げると群れは減る。プリセットは20%にしてある。
- 効いているのは予期の方で、追尾だけでは何も起きない。追尾は予期に足すと少し上乗せになる。
- ばらつき（変異角）が全方位（180°）でないと成立しない。120°以下では候補の扇形が重ならず、かたまりができない。本にも、変異角が大きいほど密で遅い群れになるとある。
- ただし、一つの大きな群れにはならない。小さなかたまりは自分たちだけで動けるので、他のかたまりを探しに行かない。本のモデルは狭い周期境界の格子に200個体を置いているので、密度と時間の違いが大きい。
- 向きは揃わない（整列度は雑音の範囲）。これは本の実データ（密度と定向性は独立）と同じ傾向。
